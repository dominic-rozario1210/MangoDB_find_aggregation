# MongoDB Aggregation Practice

## About
This repository contains MongoDB practice questions and solutions to improve my understanding of MongoDB queries and aggregation pipelines.

## Topics Covered
- Basic queries using `find()`
- Comparison operators (`$gt`, `$lt`, `$ne`)
- Logical operators (`$and`, `$or`)
- `$in` and `$nin` operators
- Aggregation pipeline using `aggregate()`
- `$lookup` and `$unwind`
- `$group` and `$avg`
- `$project` and `$sort`
- Calculations using `$multiply`

## Practice Questions
- Find products based on category and price.
- Find products that match multiple conditions.
- Display order details with product information.
- Calculate the average price for each category.
- Calculate total inventory value for each product.
- Calculate the total amount for every order.
- Sort products and orders based on price and total amount.

## Technologies Used
- MongoDB
- MongoDB Query Language (MQL)

## Purpose
To improve my MongoDB query-writing skills and prepare for technical interviews through practical exercises.
